# 帥V 私人車庫 · THE ATELIER（視覺預覽）

這是 C 版「單車鑑賞室」首頁的**靜態視覺改版預覽**，與 ChatGPT 託管的正式站完全分開。

- 預覽站：https://vincentlai123.github.io/shuai-v-bike-atelier/
- 正式站（未受影響）：https://shuai-v-bike-system.vinlai125.chatgpt.site

## 說明
- 純 HTML + CSS，無密碼、無登入、無後端。
- 工具卡片（車庫管理、齒比工作台、曲柄相容性、BIRDY 比較）與「開啟我的車庫」皆為 `#` 佔位連結。
- **3D WebGL 展廳未移植**：此處以 SVG / CSS 靜態展台示意，不含 Three.js，也未複製正式站的任何 3D 車體模型資產。
- 車隊資料同步於 2026-11-05（Rohloff / HELIX 已售出，不列入現役）。

## 設計方向
石墨黑底、暖奶油色文字、香檳金主色，保留一抹薄荷綠延續 V 品牌；大尺寸編輯式字體、電影感主視覺展台、2×2 工具卡。
